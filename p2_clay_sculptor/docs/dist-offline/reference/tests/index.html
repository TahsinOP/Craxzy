The Tests

Every statement in this site that can be checked by a computer in a few seconds is a test. They run with

env -u PYTHONPATH PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/python -m pytest tests -q

and take about a minute and a half, most of it in simulated presses.

What is not a test

Section titled “What is not a test”

The numbers in the result tables are measurements, not assertions: prediction errors, planning outcomes, the gains of the fallback. They are regenerated by the milestone scripts (Running It) and written to results/*.json; the figures and the results/Mx.md reports are produced from those files, never typed by hand.
